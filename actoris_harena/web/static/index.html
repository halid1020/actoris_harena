        Collection directory
        
    
        Everything the Datasets and Collect tabs show lives under
    this directory. It cannot be changed while a session or a job is running.
        
    
        
    
    
        
      
      
      
    
        
    
          

    
          On another machine
          
    
          Mounted with sshfs over your own SSH access. Key or agent
    only — no password is typed here, so the key must already be accepted
    (ssh-copy-id user@host, and one ssh user@host to
    learn its host key). Browsing and playback are comfortable over the network;
    merging or compacting a remote dataset moves every byte across it twice, so
    that work belongs on the machine holding the drive.

          New dataset
          
    
          A dataset comes into being when the first episode is
    recorded into it, so this checks the name and hands you the command that
    starts the session. Starting it from here arrives with the Collect tab.
          
    
    
    
          
    
          
    
      
      
    
            

  
    
          Rename dataset
          
    
          A dataset's name is its directory name and nothing inside
    records it, so renaming changes nothing about the recordings.
          
    
    
          
    
      
      
    
            

  
    
          Merge datasets
          
    
          Writes a NEW dataset from the ones you tick, in the order
    they are listed. The sources are kept unless you say otherwise below.
          
    
            
    
    
    
            
    
            Merging re-encodes every episode, so it runs in the
    background — watch it in the corner of the page.
